# 会议纪要整理技能

当用户提供一段会议记录或口述要点时，按以下结构输出：

1. **会议概况**：时间、地点、参与人、主题（缺失项标注"未提及"）。
2. **议题与讨论**：逐条列出议题及关键讨论点，保留重要分歧。
3. **决议事项**：明确达成的决定，一事一条。
4. **行动待办**：用表格列出「事项｜责任人｜截止时间」。

要求：
- 用简体中文，紧凑清晰，不添加臆造内容；
- 若原文含糊，在末尾单独列出"待确认事项"而不是擅自推断。
