## 4. 特别注意

1. **罗舒涵给了两个手机号**（`13371637051;13371677253`）。O2OA 的 `mobile` 是**单值**字段：
   `BaseAction.checkMobile` → `Config.person().isMobile()` 用 `person.json.mobileRegex` 对**整串**
   做 `Pattern.matches`，**没有 split**（`config/Person.class` 里只有 Pattern/Matcher）⇒ 带 `;` 必 500：
   `手机号 13371637051;13371677253 错误,不能为空,且必须符合指定格式.`
   - 现处理：主手机号 = `13371637051`；第二个号 `13371677253` 存入**人员属性「备用手机号」**（信息不丢）。
   - 如需改主号为 `13371677253`、或删掉该属性只留一个号，一句话即可调整。
2. **孟弋洁** 持有 `Manager@ManagerSystemRole@R` 系统管理员角色（本次未改动）。邮箱已改、
   手机号原本就是 `18516833076`、密码按指令**未重置**（`xchangePasswordTime` 仍是 2026-09-20 的历史值）。
3. 邮箱域名由占位 `@cfia.local` 统一迁移到真实域名 `@ccia.xin`。
4. 校验规则：手机号正则
   `(^(\+)?0{0,2}852\d{8}$)|(^(\+)?0{0,2}853\d{8}$)|(^(\+)?0{0,2}886\d{9}$)|(^1(3|4|5|6|7|8|9)\d{9}$)`；
   邮箱走 `StringTools.isMail`；**mobile 与 mail 均做唯一性校验**（重复报
   `ExceptionMobileDuplicate` / `ExceptionEmployeeDuplicate`）。
5. **登录失败会累计 `failureCount`**：满 `person.json.failureCount`（本机 = 5）即 `LOCK`
   （`status=LOCK`、`lockExpireTime=now+failureInterval`，本机 `failureInterval=10` 分钟）。
   且 **成功登录不会清零 `failureCount`**，只有"距上次失败超过 `failureInterval` 分钟"的
   下一次失败才把计数重置为 1。⇒ **任何验证脚本都要克制失败尝试**。
