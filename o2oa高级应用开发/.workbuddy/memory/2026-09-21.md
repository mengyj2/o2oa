## 第八轮：系统设置「编辑组件」点确定无反应（根因定案）

**现象**：秘书长在 系统设置→资源部署→组件资源 的「编辑组件」对话框（name=workmanage/title=工作管理/path=workmanage，挂 工作管理.zip）点「确定」，无任何反应：不弹错、对话框不关、组件不建。

**根因（jar+线上api.json 实证，100% 坐实）**：
- 前端 chunk `x_component_systemconfig/$Main/js/3976.js`（ComponentDeploy 模块，模块734）OK handler：
  `if(name&&title&&path){ if(componentFile.length) await Sw(file); const o=await tR(a.value); ...close() } else notice(componentDataError)`
  —— **整个 async 无 try/catch**。
- `Sw(file)` = `o2.Actions.load("x_program_center").ModuleAction.dispatchResource(false, formData, file)`。
- **10.0.2 线上 `/x_program_center/describe/api.json` 的 ModuleAction 只有 list/compare/write/output 等 10 个方法，没有 dispatchResource**（war 内 class/源码同样没有；旧版 x_component_Setting/SettingModuleResource.js 也调它=死代码）。

- 不挂 zip 时走 `tR()`=`x_component_assemble_control ComponentAction.create`（存在）→ 能建条目但 webServer 无 `x_component/workmanage` 前端资源，点图标空白。

**可用的替代接口（10.0.2 实测存在）**：
- `POST /x_program_center/jaxrs/deploy/web/resource/as/new/{asNew}`（DeployAction.deployWebResource，formData：file/fileName/filePath/overwrite/title/version/remark；需 `General.deployResourceEnable=true`；filePath 必须在 webServer 内、禁 `../`；zip 由 NodeAgent 经 socket `uploadResource` 落盘并解压）→ 即同页面「Web资源」tab 用的接口。
- `POST /x_component_assemble_control/jaxrs/component`（ComponentAction.create，body={name,title,path,visible,allowList,denyList,iconPath,type:"custom"}）。
- `GET jaxrs/component/list/all` / `DELETE jaxrs/component/{flag}`。

**出路**：A=拿 zip 本机路径后走 deployWebResource(filePath=x_component/workmanage 或 x_component，视 zip 内层结构) + ComponentAction.create 代办；B=若目标实为门户/网页，组件路径用 `@url…`（不显示上传框，UI 直接可用）；C=热修 chunk（升级会覆盖，不推荐）。

### ★★ 核心 bug：门户页内导航 Tab 点击无效 —— `openApplication` 会另开页签

**现象**：`e2e_biznav.js` 首跑，点「项目管理/预算管理/…」标题与高亮**都不变**，一直停在「业务总览/首页」。

**根因**：`_LIVE_JS` 里 `portal` 分支用
`openApp("portal.Portal", {"portalId":…, "pageId":…})`
→ `layout.openApplication` 因 **`Portal.options.multitask = true`** 而**另开一个新页签**
（`layout.desktop.apps` 中 appId 为空 → 每次新建实例），**不是页内切换**。

**修复**：`o2oa_portal.py` 新增 `gotoPortal(portalId, pageId)` ——
遍历 `layout.desktop.apps`，按 `a.options.portalId === 目标 portalId` 命中**当前已打开的门户实例**，
调官方 `PortalPage.js` 定义的 **`Main.toPortal(portal, page, par)`**（该函数会复用**同一窗口**重新 `loadPortal`）；
未命中（跨门户 / 无实例）才退回 `openApp` 新开页签。

```js
function gotoPortal(portalId, pageId){
  var L = layoutRef();
  var apps = (L && L.desktop && L.desktop.apps) || {};
  for(var k in apps){
    var a = apps[k];
    if(!a || typeof a.toPortal !== "function") continue;
    var op = (a.options && a.options.portalId) || "";
    if(op && portalId && op === portalId){ try{ a.toPortal(portalId, pageId); return true; }catch(e){} }
  }
```

## 第十四轮：CRM 百度地图 AK 失效弹窗修复（8 文件全闭环）

### 现象
打开 CRM 应用弹原生 alert：**「APP被您禁用啦。详情查看：http://lbsyun.baidu.com/apiconsole/key#。」**
URL `http://10.0.0.149:9090/x_desktop/app.html?app=CRM&status={}`。弹窗阻塞交互，但 CRM 主体渲染正常。

### 根因（实证链，非推测）
```
CRM 硬编码 2016 年旧 AK Qac4WmBvHXiC87z3HjtRrbotCE3sC9Zg
  → 该 AK 已被删除。verify 接口实测：
    curl "http://api.map.baidu.com/?qt=verify&v=2.1&ak=<AK>"
    → {"error":201,"error_msg":"APP被用户自己删除","popup":0}
  → 百度前端 SDK 内置表 ta[201] = "APP被您禁用啦。" → alert()
```
触发点是 **Main.js / Main.min.js** 的「进入应用即 `loadDom(apiPath)`」，
不是 BaiduMap.js。**浏览器实际加载的是 min 版**（`Main.min.js` / `BaiduMap.min.js`）。

### 修复要点（优雅降级：不换 AK、不依赖外网、不删功能）
1. **只把 URL 置空不够**：`window.BDMapApiLoaded || loadDom("")` 仍执行 →
   空 URL 拿回 HTML → `SyntaxError: Unexpected token '<'`；
   其回调再 `load("BDMarkerTool.js")` → 依赖 window.BMap → `ReferenceError`。
   **必须让整个分支恒假**（`0&&!window.BDMapApiLoaded&&…` 或 `if(false && …)`）。
2. **`Main.min.min.js` 不能漏** —— 与 `Main.min.js` 同构，同样含触发段。
3. **`AddressExplorer.js` 形态不同**：`BMap.Map` 是多赋值 `var map = this.map = new BMap.Map(...)`，
   且 `createMap()` 一进来就 `new BMap.Point` → 守卫须插在 **`createMap: function( position ){` 之后**，
   不能沿用 `this.map = new BMap.Map(this.mapNode);` 这种 8 空格缩进锚点。
4. **min 文件严禁插 `/* */` 块注释**（与相邻注释嵌套冲突）→ MARK 只放文件头单行。
5. `Main.js` 的 `if( !window.BDMapApiLoaded ){` 用**窄锚点**替换，不要整块模板匹配。

### 覆盖文件（8 个，全目录 grep 实测命中清单）
`Main.js / Main.min.js / Main.min.min.js / BaiduMap.js / BaiduMap.min.js /
BaiduMap.min.min.js / AddressExplorer.js / AddressExplorer.min.js`

```
fix_crm_bmap.py 幂等复跑        → 8/8 nochange
Playwright E2E（点 7 个页签）   → DIALOGS 0 / PAGEERRORS 0
```
