# O2OA 自研应用导出包（.xapp）

> 本目录存放「中国复合材料工业协会」O2OA 实例的**自研应用设计包**，用于源码仓自含应用设计、可重新导入复现。

## 重要：本批为「线上真实态」重新导出（2026-09-26）

早期（2026-09-21）由 `def_*.py` 生成的 7 个 `.xapp` 是「按设计」快照，与线上已脱节：
应用 id 对不上、且「项目管理 / 预算管理 / 公共数据字典」三个域在线上已无对应应用。

2026-09-26 改为**按名字从线上（localhost:9090）重新导出当前真实运行的自研域**，结果如下：

| 文件 | 线上对应 |
|---|---|
| `01_工程管理应用.xapp` | 流程=工程管理 / 查询=工程管理 / 门户=工程管理 |
| `02_合同管理应用.xapp` | 流程=合同管理 / 查询=合同管理 / 门户=合同管理 |
| `04_财务管理应用.xapp` | 流程=财务管理 / 查询=财务管理 / 门户=财务管理 |
| `05_档案管理应用.xapp` | 流程=档案管理 / 查询=档案管理 / 门户=档案管理 |

- 已剔除：`00_公共数据字典.xapp`（线上无对应字典容器）、`03_预算管理应用.xapp`（线上无预算应用）。
- 每个 `.xapp` = 单文件 JSON（WrapModule），可直接在「应用中心 → 导入应用」导入。
- **权威复现来源仍是 MySQL 全库 dump（状态备份）**；本目录 `.xapp` 是可读、可选择性重导入的设计快照。

## 重新导出方法

源仓（D:\O2OA）提供脚本 `o2oa高级应用开发/build/reexport_live_apps.py`（需本机 O2OA 在线 + 管理员令牌），
按名字从线上拉回完整定义、经 `x_program_center/jaxrs/module/output` 整包组包下载。
