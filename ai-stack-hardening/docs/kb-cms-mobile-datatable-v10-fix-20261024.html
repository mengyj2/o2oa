CMS 移动端 v10 表单编辑器崩溃修复（「新建供应商闪一下」真身）

doc-rev v1.0 · 2026-10-24 · 适用 本地 Docker 自托管 O2OA 10.0.2（feature/o2oa-ai-stack / cnccia-custom）· 关联 供应商链路 #47 根因段；与「财务页 reading 'application'」#49 是不同 bug

0. 一句话结论

「新建供应商闪一下变未找到数据」的真身不是数据/权限问题：文档已创建成功（POST 200），但跳转移动端编辑器时 cms_Xform/Form.js::checkDatatableClass 引用 $all 打包清单里不存在的 MWF.xApplication.process.Xform.DatatableV10（undefined），MWF.CMSDatatable.implement(...) 抛 TypeError: Cannot read properties of undefined (reading 'implement')，编辑器永停 loading。上游原样 bug（git diff 无差异），全部 v10 表单移动端编辑全崩。

1. 根因链（五环）

#环节事实证据
1打包清单缺件gulpfile build_concat_cms_xform src 清单不含 process_Xform/DatatableV10.js 与 cms_Xform/Datatable.jsgulpfile L610-703 + grep cms/$all.js 无 V10 定义
2运行态缺类移动端编辑器链 = o2.min.js → base_document → o2m.api → cmsDocMobile + cms/$all(.min).js，不含 process Datatable 链页面 script 清单 + 探针 preDutV10="undefined"
3代码裸引checkDatatableClass 在 mobile && formStyleType==='v10' 时直接赋值后 .implement源码 L289-296
4崩溃undefined.implement 抛 TypeError，load() 中断，永停 loading浏览器栈 checkDatatableClass → load → base_document.min.js
5上游原样与 upstream/master 逐字一致，非本项目引入git diff 无差异

为什么 PC 不崩：桌面链会加载 process.Xform 全套（含 DatatableV10）；移动端链不加载。为什么「闪一下」：文档 POST 200 → 跳编辑器崩 → 回列表空 category 显示「未找到数据」，三现象叠加。

2. 修复（源码 + 产物 + 构建期三处同改）

2.1 源码（真源仓）

MWF.xDesktop.requireApp("cms.Xform", "Datatable", null, false);   // 同步补链
if( MWF.xApplication.process.Xform.DatatableV10 ){
    MWF.xApplication.cms.Xform.Datatable = MWF.CMSDatatable = MWF.xApplication.process.Xform.DatatableV10;
    if( MWF.CMSDatatableFeature ) MWF.CMSDatatable.implement(MWF.CMSDatatableFeature);
    MWF.xApplication.cms.Xform.Datatable$Title = MWF.CMSDatatable$Title = MWF.xApplication.process.Xform.DatatablePC$Title;
    MWF.xApplication.cms.Xform.Datatable$Data = MWF.CMSDatatable$Data = MWF.xApplication.process.Xform.DatatablePC$Data;
}

补链原理：cms_Xform/Datatable.js 首行同步 require process.Xform/Datatable → 带上 $Module/DatatablePC/DatatableMobile/DatatableV10 全链并定义 MWF.CMSDatatableFeature，一次同步 require 同时补足「类」与「Feature」。

2.2 产物（4 文件，双路径字节一致）

  • Form.js / Form.min.js / $all.js / $all.min.js
  • 路径 A（真源仓）：tools/patch_cms_xform.py；路径 B（驱动仓构建期）：patch/cmsxform/patch_cms_xform_datatable.py（幂等，标记 O2-CMS-DATATABLE-V10）
  • 两路径产物 4/4 diff=0；⚠️ $all 内两处同名函数，另一处是 process 版（赋 APPDatatable，功能正常），只能改 CMS 版

2.3 构建期烤入（驱动仓）
